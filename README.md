# 研学团可达性咨询的行程解释

研学接待文本采用 UTF-8 编码，人物、单位和记录均为合成内容。

| 资料 | 字段 |
| --- | --- |
| `资料/需求.json` | `id`、`group`、`locale`、`text` |
| `资料/资源.json` | `id`、`type`、`from`、`to`、`slot`、`text` |
| `资料/接待回复.json` | `id`、`source`、`received`、`text` |

每份资料是 JSON 数组。记录中的字段值按来源原样保留为字符串，逗号和顿号可以属于字段内容。资料中可能有转述、不同的拼写以及较晚录入的更正。数字及日期在这些文件中沿用各资料自身的含义；原文位置以记录编号及文本范围定位。

## 命令

Node.js 22 环境下运行：

```sh
npm ci --offline --ignore-scripts --no-audit --no-fund
npm test          # 31 个测试：解析、评估、路线、台账、解释
npm run materials # 只读取资料，不解析正文含义
npm run report    # 打印逐组路线判定、家长说明与确认台账
```

## 模块结构

| 模块 | 职责 |
| --- | --- |
| `materials.js` | 原样读取三份资料并校验字段，不解析正文 |
| `src/citations.js` | 原句切片与引用去重，所有结论都带记录编号与字符区间 |
| `src/needs.js` | 把粤语书面词、普通话、英文近义表达解析为统一需求（硬性/偏好/条件），原句保留 |
| `src/segments.js` | 解析入口、步行、接驳、讲解路段及其限制（台阶扶手、雨天停行、提前安排、轮椅宽度、用时等） |
| `src/replies.js` | 接待回复分为确认与更正；更正会取代宣传文案并挂在具体路段上 |
| `src/assessment.js` | 逐组 × 逐路段核对硬性需求，输出 `confirmed / uncertain / blocked` 与依据 |
| `src/itinerary.js` | 枚举候选路线，强制分组不变、相邻路段可连接、时间不倒退；校验同场/错场安排 |
| `src/ledger.js` | 按团保存确认台账：更正传播、同行变更级联、缩窄需求重评、新团隔离 |
| `src/explanations.js` | 面向家长的调整说明与面向导游的按团说明，原文（含粤/英）原样引用 |
| `bin/report.js` | 串起全流程的命令行示例 |

## 判定规则要点

1. **宣传文案不能代替确认**：硬性需求（非折叠轮椅、扶手、短距离、时段、同行）没有明确依据时判 `uncertain`，并指出需要向谁确认；笼统的“无障碍可达”“可载轮椅”不会让路段变成可承诺。
2. **较晚录入的更正优先**：如接驳方澄清“小巴可载轮椅”仅指可折叠型，旧宣传条件标记 `supersededBy`，受影响路线改判 `blocked` 或 `reconfirm-required`，更正原句保留在依据中。
3. **可承诺路线的三个不变量**：团员分组不变（约定同行者走同一交通段、参加同一场次）；相邻路段地点相接且时间不倒退；只采用场馆已确认的接待条件。
4. **偏好可舍弃但须说明**：电梯等偏好落空只产生 `preference-lost`，不阻断路线，家长说明中列出被舍弃的偏好与原句。
5. **返程不照搬去程**：返程路段独立评估；“原路返程”之类描述不能证明适用相同接驳条件，没有依据时同样判 `uncertain`。
6. **确认与团号绑定**：新团台账为空，不能复用旧确认；部分成员改变同行约定时，只把必须一同重约的路段/场次级联标记，其余安排保持有效。
7. **决定可复现**：导游按团领取说明时，每条确认都能回溯到原判断依据（记录编号 + 原句）以及使其失效的回复。

## 本批资料的结论摘要

- **低年级同行组**（两部轮椅仅一部可折叠、须与老师同行、台阶要扶手、讲解 13–15 点开始）
  - 北门路线 `s1→s2`：s1 未说明轮椅如何通行且无步行用时、s2 只有“接受两部轮椅”宣传，均**尚不确定**，须再确认；另有“雨天停行”“须提前安排”两项义务。
  - 西门路线 `s3→s4`：经 v2 澄清后 s3 只接可折叠轮椅，对该组 **blocked**；可更换接驳或经团方同意改用可折叠轮椅。
  - `s5→s1→s2` 因 s5(13:05) 晚于 s1(13:00) 时间倒退，**路线不成立**，换入口也必须连得上后续讲解。
- **家长观察组**（可短距离步行、可走有扶手台阶、电梯仅偏好）
  - 西门路线 `s3→s4` 各硬性需求有据且 v1 已确认 14:15 场次，**可以承诺**；电梯偏好舍弃并在说明中注明英文原句。
  - 北门路线 s1 的短距离步行没有用时依据，仍为**尚不确定**。
- 两组可错开使用讲解厅，也可按 v3 同场听 13:25；同组不得拆到不同交通段或场次。
